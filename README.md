# Login Hola Mundo

Login con usuario y contraseña. Al entrar muestra "Hola mundo".

## Probar en tu computadora
1. Instala Node.js (versión 18 o superior).
2. En esta carpeta ejecuta: `npm install` y luego `npm start`
3. Abre http://localhost:3000 — credenciales de prueba: admin / 1234

## Desplegar en Render
- Tipo de servicio: Web Service
- Build Command: `npm install`
- Start Command: `npm start`
- Variables de entorno: `APP_USER` y `APP_PASSWORD` con tus credenciales reales
